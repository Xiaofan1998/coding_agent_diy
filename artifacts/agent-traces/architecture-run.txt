## 五、Agent Loop（`agent-loop.js`）

**Hybrid 架构 = ReAct 规划 + Function-Calling 执行**：

```
runAgentLoop()
  while(true):
    ├─ 注入 steering 消息（运行中插话）
    ├─ modelClient.createResponse()  → text + functionCalls
    ├─ 无 functionCall → 输出 finalMessage（检查 followUp 后 break）
    └─ 遍历 functionCall:
        ├─ suggestedFirstTool 强制重定向（可通过策略开启）
        ├─ executeTool() → 标准化/截断/错误捕获
        ├─ 记录 tool_call trace
        └─ 重复签名检测（(name+args+output)）→ 停滞重定向
```

三重保护：**首工具策略** / **停滞检测** / **上下文压缩**（`microcompactContext`）。

## 七、治理与策略（`tool-governance.js` + `strategy-mode.js`）

**三档策略（实测 `strategy-mode.js`）**：

| 模式 | maxToolRisk | subagentMaxToolRisk | autoRunDeliveryWorkflow | enforceSuggestedFirstTool |
|------|------------|--------------------|------------------------|--------------------------|
| balanced | caution | caution | ✗ | ✗ |
| conservative | **safe** | safe | ✗ | ✓ |
| autonomous | **restricted** | caution | ✓ | ✗ |

**执行拦截链**（`runtime.executeTool`）：
```
executeTool(name, args)
  ├─ getEffectiveToolPolicy（区分主/子 agent）
  ├─ findApprovedToolPolicyOverride（查精确参数授权）
  ├─ assertToolAllowed(tool, policy)
  ├─ 拦截 → createApprovalRequestForPolicyBlock + enrichErrorWithRecovery
  └─ tool.execute(args)
```

**双重安全锁**：
1. **策略闸门**：风险超限 → 生成 approval request，批准后按 `toolName + 精确 args` 重试。
2. **Governance Hold**：存在未审批请求时，子 agent 工具集**自动降级为只读**。
