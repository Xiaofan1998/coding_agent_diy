## 五、Agent Loop（`core/agent-loop.js`，335 行）

**Hybrid 架构 = ReAct 规划 + Function-Calling 执行**

```
runAgentLoop()
  while(true):
    ├─ 注入 steering 消息（运行中插话）
    ├─ modelClient.createResponse()  → text + functionCalls
    ├─ 无 functionCall → 输出 finalMessage（检查 followUp 后 break）
    └─ 遍历 functionCall:
        ├─ suggestedFirstTool 强制重定向（策略可开启）
        ├─ executeTool() → 标准化/截断/错误捕获
        ├─ 记录 tool_call trace
        └─ 重复签名检测（(name+args+output)）→ 停滞重定向
```
三重保护：**首工具策略** / **停滞检测** / **上下文压缩**（`microcompactContext`）。
