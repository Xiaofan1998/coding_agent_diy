# Roadmap

## Near-Term

- strengthen release packaging and plugin install automation
- add richer plugin-bundle validation in smoke tests
- improve preview hub ranking and attention signals
- keep machine-state / preview-state schemas stable and documented

## Runtime And Governance

- extend governance reasoning into more autonomous decisions
- deepen approval-aware execution and retry workflows
- improve subagent scheduling heuristics using governance and workflow reasons
- add richer approval/review cross-linking and finalization rules

## State And Integration

- publish more formal JSON schema / contract docs for external consumers
- evolve machine-state diff into richer categorized summaries
- provide more compact state payloads for automation and UI embedding
- add explicit integration examples for orchestration backends

## Demo And UI

- evolve the static demo into a fuller frontend shell
- improve preview-home filtering, ranking, and event timelines
- unify preview hub and demo app visual language further
- add direct preview-state driven interactions and lightweight routing

## Distribution

- package the project as a cleaner Codex plugin bundle
- document installation paths and compatibility expectations
- prepare a more explicit release process for `0.x` milestones
